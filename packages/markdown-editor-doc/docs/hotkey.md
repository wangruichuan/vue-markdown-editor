# 快捷键
| 工具名称 | 快捷键 | 描述 |
| --- | --- | --- |
| Bold | Ctrl B | 粗体 |
| Italic | Ctrl I | 斜体 |
| Underline | Ctrl U | 下划线 |
| Delete | Ctrl Shift X | 删除线 |
| Quote | Ctrl Shift Q | 引用 |
| Ul | Ctrl Alt U | 无序列表 |
| Ol | Ctrl Alt O | 有序列表 |
| InlineCode | Ctrl Alt I | 行内代码块 |
| Code Block | Ctrl Alt C | 代码块 |
| Link | Ctrl Alt L | 链接 |
| Add Image | Ctrl Shift I | 添加图片 |
| Table | Ctrl Alt T | 表格 |
| FullScreen | Ctrl Alt F | 全屏 |
| Write | Ctrl Alt P | 只写 |
| Read | Ctrl Alt R | 只读 |
