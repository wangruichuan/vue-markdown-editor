介绍 ​

Markdown Editor 是基于Vue3开发打造的高效、灵活且功能丰富的 Markdown 编辑工具。 为开发者与用户提供了便捷的使用体验。

特性 ​

  • 响应式设计：充分利用 Vue 3 的响应式系统，当输入内容发生变化时，编辑器能够实时更新预览，让用户即时看到 Markdown 转换后的效果。
  • 组合式 API：采用 Vue 3 的组合式 API，使得代码逻辑更加清晰、可复用，便于开发者进行功能扩展和定制。
  • 标准语法支持：支持完整的 Markdown 标准语法，包括标题、列表、代码块、引用、链接等，满足日常文档编写的基本需求。
  • 实时预览：编辑器提供实时预览功能，用户在输入 Markdown 内容的同时，右侧预览区域会实时更新渲染结果，方便用户及时查看和调整内容。
  • 快捷键支持：支持丰富的快捷键操作，如加粗、倾斜、插入链接、插入代码块等，提高用户的输入效率。
  • 代码高亮：对于代码块，编辑器提供多种语言的代码高亮显示，增强代码的可读性。
  • 同步滚动：编辑预览实时同步滚动，精准高效。

贡献与支持 ​

欢迎社区开发者的贡献！如果你发现了 bug 或者有新的功能建议，欢迎在我们的 GitHub 仓库提交 issue 或 pull request。同时，如果你在使用过程中遇到任何问题，也可以在社区中寻求帮助。
